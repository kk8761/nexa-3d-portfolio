# Nexa 3D Portfolio

Welcome to my 3D interactive portfolio! This project showcases my skills, experience, and projects in an immersive 3D environment.

## 🌐 Live Demo
Check out the live version of my portfolio here: [https://kkrprofile.netlify.app/](https://kkrprofile.netlify.app/)

## 🚀 Technologies Used
This portfolio is built using modern web technologies to create a high-performance 3D experience:

| Technology | Purpose |
| :--- | :--- |
| **Three.js** | Core 3D engine |
| **React Three Fiber** | React integration for Three.js |
| **React Three Drei** | Useful helpers for 3D components |
| **Tailwind CSS** | Styling and layout |
| **Framer Motion** | UI animations |
| **Vite** | Build tool |

## ✨ Key Features
* **Interactive 3D Elements:** Engaging 3D scenes and models.
* **Responsive Design:** Optimized for both desktop and mobile viewing.
* **Smooth Animations:** Fluid transitions powered by Framer Motion.
* **Project Showcase:** A clean interface to highlight my recent work.

## 💻 Local Installation
To run this project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kk8761/nexa-3d-portfolio.git
   ```

2. **Navigate into the directory:**
   ```bash
   cd nexa-3d-portfolio
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```
